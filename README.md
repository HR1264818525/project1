# project1
快递驿站包裹入库、分拣与取件业务模拟

## 主要功能
- 包裹分拣、入库
- 取件、出库
- 物品类型分类
- 系统身份管理
- 物流信息确认

- 包裹分拣 - 按快递公司、区域分类       //优先完成前两项
