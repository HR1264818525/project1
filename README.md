# 快递驿站管理系统

## 1. 项目背景与业务场景
快递驿站是末端物流的重要节点，每天需要处理大量包裹的暂存与领取。传统人工记录方式效率低、易出错，本系统旨在用程序实现数字化管理。
实际业务流程是这样的：快递员把包裹送到驿站，工作人员录入信息入库，系统自动生成取件码发给收件人，收件人凭码来取件。系统还要支持按手机号查询，以及查看整个驿站的库存状态。

## 2. 核心系统架构
- 三级单向链表嵌套：
最外层是货架链表，每个货架节点包含层链表头指针；中间层是货架层链表，记录层号、容量、当前数量及包裹链表头；最内层是包裹链表，存储单号、姓名、电话、取件码和状态。全局只有一个 shelfHead 指针管理所有货架。
插入采用头插法O(1)，查找和删除都是线性遍历O(n)。

### 三级链表设计
系统设计了三个结构体，形成层级关系。
Package包裹结构体包含：快递单号ID、收件人姓名、联系电话、6位取件码、状态标记、以及指向下一个包裹的指针。状态标记有两个取值：在库和已取件。
ShelfLevel货架层结构体包含：层号、最大容量、当前包裹数量、指向该层包裹链表的头部指针、以及指向下层的指针。
Shelf货架结构体包含：货架ID、总层数、指向该货架层链表的头部指针、以及指向下一个货架的指针。
### 全局状态
整个系统通过一个全局指针shelfHead管理所有货架。创建货架时动态分配内存，用addShelf函数挂到链表尾部。这种设计简单直接，但缺点是难以支持多实例，也不利于单元测试。
### 初始化过程
系统启动时自动创建2个默认货架，每个货架5层。创建货架的函数内部会循环调用创建层的函数，每层容量也设置为5。这意味着系统初始总共10层，每层最多放5个包裹。

货架链表 (Shelf)
    │
    ├── 货架1 [编号, 总层数]
    │   ├── 第1层 [容量, 当前数量]
    │   │   └── 包裹A → 包裹B → NULL
    │   ├── 第2层
    │   └── 第3层
    │
    ├── 货架2
    │   ├── 第1层
    │   └── ...
    │
    └── NULL


## 3.核心功能详解

### 包裹入库流程
用户依次输入快递单号、收件人姓名、联系电话。系统调用随机数函数生成6位数字取件码，每位都是0到9的随机数。然后显示当前所有可用货架列表，用户选择货架号和层号。系统做四重校验：货架是否存在、层号是否在该货架范围内、该层是否已满、该单号是否已在该层存在。全部通过后，用头插法将包裹加入该层的包裹链表，并更新当前数量。
头插法的优势在于不需要遍历到链表尾部，直接插在头部，时间复杂度是常数级O(1)，效率很高。
### 包裹取件流程
用户输入6位取件码。系统从最外层货架链表开始，逐层深入到每个货架的每一层，遍历该层的所有包裹。三重循环依次是：货架循环、层循环、包裹循环。
找到匹配的包裹后，需要处理链表节点删除。这里要分两种情况：如果删除的是头节点，直接把链表头指针指向下一个节点；如果删除的是中间或尾部节点，需要前驱指针的next跳过当前节点。删除后释放内存，减少该层计数。
### 手机号查询流程
输入手机号后，同样三级遍历所有货架、层、包裹。但只显示状态为"在库"的包裹，已取件的不会显示。输出信息包括单号、姓名、取件码、具体位置。
### 查看货架功能
递归式打印所有信息：先打印货架ID和总层数，再逐层打印层号和容量使用情况，最后逐个打印该层所有包裹的详细信息，包括单号、姓名、取件码和状态。




## 4. 函数模块

### 状态定义
- IN_STORAGE：包裹在库中
- PICK_UP：包裹已取件

### 初始化模块

initRandomSeed()	基于当前时间初始化随机数种子
generatePickupCode()	生成6位数字取件码
createPackage()	创建新包裹节点（包含随机取件码生成）
createLevel()	创建货架层节点
createShelf()	创建货架并自动创建指定数量的层

### 管理辅助模块

addShelf()	将货架加入全局货架链表
findShelfById()	根据货架ID查找货架
findLevel()	在指定货架中查找指定层
storePackage()	包裹入库（支持重复检测、容量检测）
findByPhone()	根据手机号查询在库包裹
printAllShelves()	打印所有货架、层、包裹的详细信息
freeAll()	递归释放所有动态分配的内存（防止内存泄漏）

### 交互模块（菜单功能）

1	menu_StorePackage()	包裹入库（输入单号、姓名、电话，选择货架和层）
2	menu_PickupPackage()	包裹取件（输入6位取件码）
3	menu_SearchByPhone()	手机号查询在库包裹
4	menu_ViewAllShelves()	查看所有货架及包裹信息
0	—	退出系统并释放内存


## 总结
本系统是一个结构清晰、功能完整的入门级C语言项目，适合用于学习： - 链表数据结构的嵌套使用 - 动态内存管理（malloc/free） - 模块化程序设计 - 命令行交互程序开发
